# 交互设计（INTERACTION-DESIGN）· 场景操作路径 + 录入双通道

> 来源：用户 2026-10-24 补充需求——"每个场景细化操作路径，从首页入口开始到功能完成返回首页；增删改查可手工操作，但**默认 AI 协助**——大部分患者不懂数据库，编辑功能太多会让交互门槛更高。"
> 本文与 PATIENT-FLOW（页面树来源）、SCENARIOS（场景定义）同批签认（G1 包新增件）。

## 一、总原则：AI 协助默认，手工永远可及，入口收敛

1. **录入/修改的第一入口是 AI 协助**：患者用一句话（或一张照片/一份 PDF）描述，AI 产出**结构化候选**，患者核对后确认入库。不要求患者理解"字段/表/数据库"。
2. **手工操作永远可用但不抢占视觉**：每个卡片右上「⋯ 更多」里收口：手工补一条 / 改这一条 / 删除（=更正，见 4）；一屏**显式编辑按钮 ≤1 个**；长表单禁止平铺，全部藏在「+ 手工添加」之后。
3. **统一心智：一切 AI 产出都是候选**（与 MinerU 解析候选同一模型）：候选 → 逐项核对（可改可删）→ 确认才入事实层；拒收无副作用。AI 说错是常态预期，核对界面每项都给"不对，改一下"的直达入口。
4. **删除即更正**：家族契约③——更正只新增版本，界面语言用"改这一条"，不出现"删除记录将不可恢复"式数据库语言。
5. **回首页永远一步**：所有二级页左上返回 + 顶栏品牌点击回看板；任务完成 Toast 内嵌"回到看板"。

## 二、场景操作路径（首页 → 完成 → 回首页）

格式：**入口**（看板上的哪块）→ 步骤 → **产物** → 回首页。AI=AI 协助路径（默认），手=手工路径（收敛入口）。

### P0 场景

**S01 分子报告读不懂**
- 入口：看板「关键变化条」出现"新报告"提示，或双主体入口①「看看我的瘤」。
- 路径：我的瘤→分子档案 → 点不懂的那项 → 展开人话解释 + 检测日期/方法 → 「把这个问题记下来」按钮把术语问题加进问题清单。
- 产物：问题清单 +1；分子档案页可导出摘要。
- 回首页：解释卡底部「回到看板」。手：报告没录全 → 「⋯更多 → 手工补一项标志物」（三态单选）。

**S02 TMZ 服药日记**
- 入口：看板本人入口①「今天 D 几、该不该吃」。
- 路径：放化疗日历→Stupp 日程 → 今日卡（D3/吃药日）→ 点「已服」/「吐了一次」；AI 路径：右栏 AI 面板说"今天 D3 吃完吐了" → 候选"呕吐一次，是否顺延请咨询" → 确认入周期记录 + 自动生成问题清单条目。
- 产物：周期打卡 + 问题清单 +1。回首页：打卡后 Toast「记好了，回看板」。

**S03 电场佩戴与头皮**
- 入口：看板照护者入口①「贴片换了吗 / 今天戴够了吗」。
- 路径：电场治疗→佩戴与时长 → 今日滑条（默认记忆昨日时长，拖一下即可）→ 头皮异常 → 「记一次头皮反应」；AI：拍贴片部位照片说"这里红了" → 候选（部位/程度词）→ 核对入库。
- 产物：日佩戴 +1、皮肤事件 +1；周统计即时更新。回首页同上。

**S04 随访 MRI「增大」**
- 入口：看板「接下来」卡「3 天后复查」或关键变化条「新 MRI 已登记」。
- 路径：随访影像→MRI 并列 → 历次并排（结论原文/当时激素/当时 KPS）→ 底部「这次我想问医生」→ 勾选预生成问题（灌注成像？减激素后怎么读？）可增删 → 存入问题清单。
- 产物：问题清单（fact 区）；复诊导出直接带上。手：新报告 → 「登记一份 MRI」（3 个字段：日期/结论原文照抄/当时激素）。
- 红线：全程无判读文案。回首页：清单保存 Toast。

**S05 激素减量与症状**
- 入口：看板关键变化条「激素 4→2mg 第 3 天」。
- 路径：指标与用药→激素剂量 → 阶梯时间线（与症状同轴）→「记一次症状」；AI："今天头痛比昨天重" → 候选（症状/时间/与减量的时间关系自动标注）→ 确认。
- 产物：症状点落在激素轴上。回首页同上。

**S06 癫痫发作代记**
- 入口：看板照护者入口②「记一次发作」。
- 路径：症状与发作→癫痫轨道 →「+ 记一次」（4 个必填：什么时候/多久/什么样子[类型单选]/谁看到的[患者/照护者]）→ 保存即生成事件卡；AI："凌晨两点他抽了一分半，左手抖" → 候选（时间/时长/局灶性/照护者代记）→ 核对。
- 产物：事件卡 + 复诊自动汇入。回首页 Toast「已记录，复诊时会带上」。

**S07 照护决策与 ACP 线索**
- 入口：看板照护者入口③「最近在想的事」。
- 路径：照护与家事→决策与 ACP → 话题列表（open/discussed/filed 三态）→「开一个话题」（话题名 + 一句备注）→ 与家人谈过后回来更新状态；private 感受走「当下感受」卡（作者角色徽章）。
- 产物：决策台账；导出时 private 自动过滤。回首页同上。

**S08 复诊准备**
- 入口：看板「接下来」卡「下周三复诊」。
- 路径：复诊与试验→就诊准备与导出 → 两区预览（fact=分子/MRI 并列/发作汇总/当前方案；view=我的问题清单）→ 「生成摘要」→ 预览 → 「复制/导出」→ 勾掉 private 的确认条（默认已过滤，展示"已隐藏 N 条私密记录"）。
- 产物：Markdown 摘要。回首页：导出完成 Toast。

### P1 场景（路径要点）

- **S09 血象低**：看板关键变化「WBC 2.8 ↓」→ 指标与用药→血象卡 → 翻面看区间/分级 → 「记一次感受（乏力）」与指标并排。手：抄单 4 个数字（WBC/ANC/PLT/HGB）；AI：拍化验单 → 候选数值 → 核对。
- **S10 认知变化**：照护与家事→认知与人格 →「记一个变化」（什么变了/什么时候/影响）+ MoCA 分并列展示（不画趋势线）。
- **S11 营养双线**：营养与体重→进食与体重 → 体重快记（数字键盘）/进食三选一（吃得下/勉强/吃不下）；激素语境说明常驻。
- **S12 试验线索**：复诊与试验→试验线索 → 筛选（分期/状态）→ 卡片只显药名+期别+"登记状态，未核实" → 「收藏」入已收藏。
- **S13 文档导入**：复诊与试验→资料库 → 「导入 PDF」→（有 Token）MinerU 解析 → 候选逐项核对 → 确认入事实层；（无 Token）提示三动作（18 号 §6）。失败原件保留可重试。

## 三、CRUD 通道矩阵（AI 默认 / 手工可及）

| 实体 | AI 协助（默认） | 手工（收敛入口） | 说明 |
| --- | --- | --- | --- |
| 发作事件 | 对话/语音→候选 | 「+记一次」4 字段表单 | 代记徽章必选 |
| MRI 登记 | 报告拍照/PDF→候选（日期/结论/激素） | 3 字段小表单 | 结论照抄原文 |
| 分子标志物 | 报告解析→三态候选 | 「⋯→补一项」三态单选 | 未检测≠阴性 |
| 指标数值 | 拍化验单→候选 | 数字键盘快录 | 每项可改可拒 |
| 激素/用药变更 | 对话→候选 | 阶梯图上「记一次调整」 | 无建议文案 |
| 症状/感受 | 对话→候选 | 卡片「记一次」 | 感受默认 private 可选 shared |
| 电场日记录 | （设备月报导入→候选） | 滑条 5 秒快记 | 空态不编数据 |
| 问题清单 | 场景页一键生成 + AI 补充建议 | 直接编辑文本 | fact/view 分区 |
| 决策话题 | —（不 AI 生成临终话题，红线） | 「开一个话题」 | 状态三态 |
| 手术记录（评审补） | 出院小结 PDF→候选（日期/切除程度原文） | 「⋯→补一次手术」 | 切除程度只抄报告 |
| 方案变更（评审补） | 对话"医生说下周期减量"→候选 | 阶梯图「记一次变更」 | 变更留痕不删旧 |
| AED 调整（评审补） | 对话/处方照片→候选 | 药卡「改剂量/停」 | 血药浓度数值走指标 |
| 量表分数（评审补） | —（不做 AI 估分，红线） | MoCA/KPS「记一次分数」 | 只抄分不做趋势解读 |
| 删除/更正 | 对话"把上次体重改成 72.5" → 候选 diff | 「⋯→改这一条」 | 更正=新增版本，界面不出现"不可恢复" |

**门槛红线**：任何页面显式编辑入口 ≤1；所有 AI 候选必经核对；手工表单字段数 ≤6；数字输入用键盘组件不用文本框；错误恢复=拒收候选零副作用。

## 四、对原型（prototypes/v0.2）的落地要求

1. 看板双主体 8 入口按本文 §二 的入口定义（本人 4 + 照护者 4）。
2. 每个一级页至少一处「AI 协助示例按钮」（把预写提示词放入右栏 AI 输入框但不自动发送——家族"不代替患者发言"契约）。
3. 卡片「⋯ 更多」菜单含：手工补一条 / 改这一条 /（资料类）看原文。
4. 本文档路径与原型页签一一对应：M2 验收时按 §二 逐场景点一遍（G2 走查脚本）。

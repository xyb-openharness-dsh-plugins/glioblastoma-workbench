> 格式（26 号 §4.2）：一段场景 = **患者原话 / 页面接住 / 明确不做什么**。第三项缺了，功能线一定越界说结论。
> 引语口径（评审 P1 修复）：标注「设计假设」的场景，其"患者原话"为**文献语境改写**，非一手引语；一手访谈回填前不得当真实引语引用（USER-RESEARCH §六-1）。
> 追踪链：证据/假设 E → 需求 N → 场景 S → 功能 F → 数据/交互 → 验收 A（G1 签认时逐条对齐）。
> 证据已回填（2026-10-24）：⏳ 标记各行的证据见 USER-RESEARCH §二/§三 与素材层 `research-notes/{user-research,medical-constraints}.md` 对应层（患者研究 A / 照护者研究 B–C / 患者组织 D / 困惑句 F / 医学主题 1–10）；标注「设计假设」的条目仍需 G1 用户确认。

## 一期主场景（P0）

S01 分子报告读不懂
- 患者原话："IDH 野生型""MGMT 未甲基化"，这些字我每个都认识，连起来不知道对我的治疗意味着什么。
- 页面接住：我的瘤 → 分子档案：每项标志物三态（检出/未检出/未检测）+ 检测日期/方法 + 一句人话解释（"解释不是判断"常驻）。
- 不做什么：不推算预后、不给生存数字、不说"你对 XX 药会敏感"（MGMT 只做术语解释，敏感性判断归医生）。
- 证据：⏳ E-医学（主题2）＋E-患者（信息差典型困惑句）

S02 TMZ 服药日记
- 患者原话：这个 28 天的药，今天到底是第几天、该不该吃、上周吐了一次算不算漏服？
- 页面接住：放化疗日历 → Stupp 日程 + TMZ 周期：28 天日历高亮 D1–5、服药/漏服/呕吐记录、周期进度；同步放化疗段显示放疗次数累计。
- 不做什么：不判断"漏服一次要不要补"、不调整剂量；只记事实 + 生成"问医生"条目。
- 证据：设计假设（临床事实：28 天周期 D1–5 为通用方案结构）

S03 电场佩戴与头皮（家族独有）
- 患者原话：今天戴了 16 个小时还差得远吗？贴片底下痒得厉害，能抠吗？
- 页面接住：电场治疗 → 佩戴与时长（日记录条 + 周统计 + ≥18h 目标语境线）/ 贴片与头皮（更换日期、皮肤反应记录、护理提示卡）。
- 不做什么：不说"必须戴满 18 小时否则白戴"、不判断皮肤反应分级要不要停；记录与出处归设备报告和医生。
- 证据：⏳ E-患者（照护者日常句）

S04 随访 MRI「增大」（家族独有决策困惑）
- 患者原话：报告写"术区强化范围较前增大"，是假性进展还是复发了？全家吵了一晚上。
- 页面接住：随访影像 → MRI 并列：历次报告逐条并排（日期/结论原文/当时激素用量/当时 KPS），生成「问医生的问题清单」（含"是否需要磁共振波谱/灌注""激素试减后的影像变化怎么看"这类患者真会问的问题）。
- 不做什么：**不判读、不给"更像假性进展"类倾向**；无 is_progression 字段是数据契约红线（G3）。
- 证据：⏳ E-患者 + E-医学（主题6）

S05 激素减量与症状反弹
- 患者原话：地塞米松从 4mg 减到 2mg，第二天头痛又来了，是瘤子又长了吗？
- 页面接住：指标与用药 → 激素剂量：mg/日时间线 + 减量事件标记，与症状记录同轴并排（同一时间窗看得见"减量→头痛出现"的先后事实）。
- 不做什么：不建议"加回去"、不判断症状归因；只呈现时间先后。
- 证据：设计假设（临床常见叙事）

S06 癫痫发作代记（双主体）
- 患者原话（照护者）：凌晨他抽了两分钟，我吓坏了，医生问什么时候、多久、什么样子，我说不清。
- 页面接住：症状与发作 → 癫痫事件轨道：单次事件卡片（时间/时长/类型/诱因/witnessed_by=照护者）+ 抗癫痫药清单；复诊前自动汇入就诊准备。
- 不做什么：不判断"这次发作意味着什么"、不建议调药。
- 证据：⏳ E-照护者

S07 照护者决策与 ACP 线索
- 患者原话（照护者）：如果真的复发了，还要不要二次手术？这些话我不敢问他，也不知道该问谁。
- 页面接住：照护与家事 → 照护决策与 ACP：决策话题清单（讨论状态：未谈/谈过/已归档）+ 每题配"和谁谈、什么时候谈合适"的信息整理；ACP 内容只列话题不列答案。
- 不做什么：不出"应该选择姑息"类建议、不按病程强制弹"该谈临终了"；状态是讨论状态不是医学结论。
- 证据：⏳ E-照护者（ACP 时机研究）

S08 复诊准备（含 private 过滤）
- 患者原话：下周三复查，我该带什么、问什么？
- 页面接住：复诊与试验 → 复查节奏（8–12 周 MRI 节奏语境）+ 就诊准备与导出（fact/view 两区，自动过滤 private；首行"不是医生结论"）。
- 不做什么：不替患者决定"必须问假性进展"；问题清单可编辑可删。
- 证据：家族通用件（不证自明，一期必上）

## 一期次场景（P1）

S09 血象低与乏力（TMZ 骨髓抑制）：指标与用药 → 血象卡（WBC/ANC/PLT/HGB，CTCAE 绝对阈值分级，背面区间与单据参考范围）＋"何时查血象"的周期语境。不判断停药。证据：⏳ E-医学（主题10）
S10 认知与人格变化记录：照护与家事 → 认知与人格（事件式记录：什么变了/什么时候/对生活影响；可与 MoCA 分数并列）。不说"这是病情恶化的信号"。证据：⏳ E-照护者
S11 营养双线：营养与体重 → 进食与体重（体重线 + 进食记录；激素期"胃口大开体重涨"与疾病期"吃不下"双语境说明）。不给饮食处方。证据：设计假设
S12 试验线索：复诊与试验 → 试验线索（四通道 GBM 口径；"登记状态，未核实"常驻；只写药名与期别）。不做药物说明、不匹配入组建议。证据：家族契约 D22
S13 文档导入与解析（MinerU）：复诊与试验 → **资料档案**（新增页签，评审 P0-① 修复）：导入 PDF 报告 → MinerU 候选 → 逐项核对入事实层；Token 三态设置页。候选永不直接入库。证据：18 号 v2 契约
S13b 感染与血栓风险记录（评审 P1 补）：症状与发作 → 感染与血栓（发热/卧床/激素期风险的客观记录；VTE 红旗为家族唯一允许的就医指引式提示，23 号语境）。证据：E-医学（主题 8/10）

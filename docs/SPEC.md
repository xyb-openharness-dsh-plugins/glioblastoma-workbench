# 项目规格 v0.1（SPEC）

状态：**草案，待 G1 签认**。确认人/日期：待 G1（本文与 SCENARIOS/PATIENT-FLOW/DIFF-MATRIX 同批签）。
产品：胶质母细胞瘤（GBM）患者与照护者工作台 · 占位品牌「小星宝 StarPal」 · `glioblastoma-workbench`。

## 0. 需求审计摘要（ai-spec 阶段1）

- **核心需求**：GBM 患者与照护者（双主体）在本机整理病程资料（手术/分子/影像/治疗/指标/症状），追踪 TMZ 放化疗与电场治疗，准备复诊与试验线索；全病程覆盖（新诊断→随访→复发→照护决策）。
- **隐含需求（非功能）**：本机优先（零依赖 http、127.0.0.1）；私密内容数据结构级分级（visibility）；判读永远归属医生（无判读列）；文案红线（E2）；演示数据单源（D10）；MinerU 候选永不直接入库（18 号 v2）。
- **缺失信息（G1 待用户拍板）**：① 一级线名与页面树（§4）② 双主体入口具体形态（看板双入口 vs 页内记录人选择）③ 二期候选确认不进一期（SCENARIOS S14–S17）。

## 1. 设计者与依据

设计者章程 `DESIGNER-BRIEF.md`；调研素材 `research-notes/{medical-constraints,user-research,family-landscape}.md`；研究原则见 NEW-CANCER-WORKBENCH §三（医生工作流不直接成为功能树；证据分层）。追踪链：E → N → S（SCENARIOS）→ F（§4）→ A（§7）。

## 2. 问题、用户与最小闭环

- **服务谁**：GBM 患者本人（认知允许时）+ 照护者/家属（常为实际记录者），双主体并重（用户 2026-10-24 确认）。
- **最难受的时刻**：分子报告读不懂（流一）；治疗期日记混乱、发作说不清（流二）；MRI"增大"恐慌与复诊准备（流三）。
- **最小闭环**：登记一份 MRI 报告 → 随访影像并列历次事实 → 生成问题清单 → 就诊准备导出（private 过滤）→ 复诊后勾"已问过"。失败恢复：导入失败原件保留、候选拒入事实层。
- **成功标准**：双主体各有"打开就知道今天做什么"的路径；三条流各自产物可导出。

## 3. 方案与 ADR

| 决策 | 选择 | 理由 | 取舍 |
| --- | --- | --- | --- |
| 架构 | 家族标准：零依赖 Node http + SQLite + file:// 原型先行 | lymphoma v0.3.0 已验证；22 号闸口要求 HTML 先行 | 不引入框架；无多用户并发（本机单用户） |
| 移植策略 | 复用骨架层（migrate/store/server/paths/backup/mineru/检查器/原型骨架），换全部领域层（13 专属表/字典/kb/画像/品牌） | E4 防换名复用 + 效率 | 领域层全新写，工作量约 60% |
| 双主体 | `author_role` 落记录行 + `visibility` 数据结构属性 + 看板双入口 | 26 号 §4.3 私密必须是数据属性 | 不做全局身份切换（避免"登录"错觉） |
| 电场/随访影像独立成线 | 一级各一条；复诊与试验合并一条 | 家族独有模块；一级重名率 10%（DIFF-MATRIX §四） | 一级数量到 10（上限） |
| MinerU | 18 号 v2 六部件（M5） | 用户确认；GBM 报告结构化价值高 | Token 维护由设置页三态+三动作兜底 |
| 模型路由 | 主线 GLM-5.3；批量检索/核对路由 GLM-5.3-Flash | 用户 2026-10-24 确认 | 质量闸口不降级 |
| 录入双通道 | **AI 协助默认，手工可及但入口收敛**（显式编辑 ≤1/页；AI 产出一律候选→核对→确认；删除=更正版本） | 用户 2026-10-24 补充；患者不懂数据库，编辑密度推高门槛 | 详见 INTERACTION-DESIGN.md（13 场景路径 + CRUD 矩阵） |

## 5. 数据与 API（G3 冻结对象，现为草案）

- 草案 `schema/draft/0001_gbm_specific.sql`（GBM 专属 11 表）+ 通用 8/指标 3/档案 2/导入 3 张（lymphoma 29 表结构平移，专属全换）。
- 四契约：无判读列；缺测 NULL ≠ 0；更正只新增版本；事实四层不合并。
- API：家族合同（`apiBase` 不含 `/api`，前缀 `glioblastoma`）；MinerU 设置接口 `GET/POST /api/glioblastoma/settings/mineru`（18 号 §5.2）。

## 6. 四核心模块

① 病情整理（我的瘤+随访影像）② 指标检测与分级（血象/激素）③ 独立病情一图秀（数值线+Stupp 治疗条+电场佩戴带；KPS/发作只节点）④ 营养/心理/照护三支柱（心理线升级双主体照护线）。

## 11. 数据模型演进关口

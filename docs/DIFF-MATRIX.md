# 差异化矩阵（DIFF-MATRIX）· 防换名复用

> 判据（26 号）：任意两个癌种并排看，一级名称一致率 > 70% 且二级顺序一致 = 没做场景调研。
> 对比基准：乳腺小粉宝（家族成熟基准，26 号 §3 口径）；移植样板：lymphoma v0.3.0。
> 状态：M1 将补全逐行走查表；本文先落认领 issue 已签的 6 条差异化种子（issue #12）。

## 一、六条 GBM 差异化种子（场景 → 功能 → 验收）

1. **分子档案线**：IDH1/2、MGMT 甲基化、1p/19q、TERT/EGFR 三态记录（检出/未检出/未检测，未检测 ≠ 阴性），人话解释 + 与治疗路径并列 → 验收：G1 签认 + G3 契约含 method/date/三态。
2. **TTFields 电场治疗档案**：日佩戴时长（≥18h 目标语境）、贴片更换与头皮反应、设备月度使用率；无"该不该戴"判断 → 验收：G2 逐页 + 红线扫描。
3. **随访影像并列事实**：每份 MRI 的日期/序列结论/当时激素用量/当时 KPS 并排展示，不判读（假性进展困惑由"问题清单"承接，不由产品判定）→ 验收：schema 无判读列 + 词表测试。
4. **激素剂量时间线**：mg/日 + 减量事件 + 症状同轴并排，无减量建议 → 验收：parity + 红线。
5. **双主体与照护者线**：visibility 私密分级（数据结构属性）、代记身份、认知状态标记、照护决策清单与 ACP 信息整理 → 验收：三出口过滤单测。
6. **癫痫独立事件轨道**：发作卡片（类型/时长/诱因）+ 抗癫痫药列表，不并入指标趋势 → 验收：读模型断言。

## 二、功能线对比（vs 乳腺小粉宝，M1 填全量）

| 功能线（26 号 L1–L10） | 乳腺做法 | GBM 做法（草案） | 刻意不同 |
| --- | --- | --- | --- |
| L2 疾病本体 | 病理·分子档案（ER/PR/HER2/Ki-67） | **「我的瘤」拆分子档案（IDH/MGMT/1p19q）+ 手术切除程度（GTR/STR/活检）两条** | 分子决定治疗预期；切除程度是独立事实线 |
| L3 治疗与决策 | 术后上肢、内分泌决策 | Stupp 日历（ TMZ 28 天 D1–5）+ **电场治疗** + 复发后路径 | 电场模块家族独有 |
| L4 指标分析 | CTCAE 分级 + ×ULN | 血象（TMZ 骨髓抑制）+ **激素剂量** + KPS（分类，不算趋势） | KPS/激素并排不判读 |
| L5 安全与症状 | 淋巴水肿 | **癫痫发作轨道** + 脑水肿症状 + 感染/血象 | 发作独立轨道 |
| L6 营养与体重 | 体重曲线 | 激素致体重增加 vs 进食下降双线 + 吞咽（后期） | 激素语境独有 |
| L7 心理与家庭 | 遗传咨询（BRCA） | **照护者决策代理 + 认知/人格改变 + ACP 信息整理** | 家属线从"辅助"升为"主体之一" |
| L8 复诊随访 | 影像随访间隔 | 8–12 周 MRI 并列 + **假性进展问题清单** | 判读困惑是核心场景 |
| L10 试验线索 | 真实登记库 | 同（unified-trial-mcp 四通道） | 通道相同，癌种专属关键词 |

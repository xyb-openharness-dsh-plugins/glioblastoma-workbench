# 差异化矩阵（DIFF-MATRIX）· 防换名复用

> 判据（26 号）：任意两个癌种并排看，一级名称一致率 > 70% 且二级顺序一致 = 没做场景调研。
> 对比基准：乳腺小粉宝 v0.12.0（26 号 §3 口径）；移植样板：lymphoma v0.3.0（实测 10 一级 / 25 二级 / 27 视图）。
> 素材来源：research-notes/family-landscape.md（2026-10-24 实测读取 lymphoma 仓）。

## 一、六条 GBM 差异化种子（认领 issue #12 已签）

1. **分子档案线**：IDH1/2、MGMT 甲基化、1p/19q、TERT/EGFR 三态记录（检出/未检出/未检测，未检测 ≠ 阴性），人话解释 + 与治疗路径并列 → 验收：G1 签认 + G3 契约含 method/date/三态。
2. **TTFields 电场治疗档案**：日佩戴时长（≥18h 目标语境）、贴片更换与头皮反应、设备月度使用率；无"该不该戴"判断 → 验收：G2 逐页 + 红线扫描。
3. **随访影像并列事实**：每份 MRI 的日期/序列结论/当时激素用量/当时 KPS 并排展示，不判读（假性进展困惑由"问题清单"承接）→ 验收：schema 无判读列 + 词表测试。
4. **激素剂量时间线**：mg/日 + 减量事件 + 症状同轴并排，无减量建议 → 验收：parity + 红线。
5. **双主体与照护者线**：visibility 私密分级（数据结构属性）、代记身份、认知状态标记、照护决策清单与 ACP 信息整理 → 验收：三出口过滤单测。
6. **癫痫独立事件轨道**：发作卡片（类型/时长/诱因）+ 抗癫痫药列表，不并入指标趋势 → 验收：读模型断言。

## 四、结构性判据自查（实测）

- 一级 10 / 二级 29（评审 P0 修订后，阈值 8–10 / 24–30 ✅）；二级为 0 的一级 = 1（看板）≤2 ✅；单线二级最大 5 ≤6 ✅。
- **与 lymphoma 一级名称一致率：1/10（仅「看板」）= 10% ≤70%** ✅；二级重名 7 处全部属于家族通用标准件（血象/进食与体重/当下感受/就诊准备/试验线索/入组问题/复查节奏），无一条业务语义重名。
- 每条线挂一句患者原话（PATIENT-FLOW 三流 + 矩阵种子 #1–#6 对应：我的瘤←#1、电场←#2、随访影像←#3、指标与用药←#4、照护与家事←#5、症状与发作←#6）。
- 与乳腺基准（8 一级/27 二级）比较：GBM 一级重合仅"看板/营养与体重"2 条语境名，差异点同上表右列。

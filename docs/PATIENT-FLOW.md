# 患者流程（PATIENT-FLOW）

> 规则（ZERO-TO-DEV §1.1）：页面树由三条真实流反推，不从医生流程照搬。
> 每条流写「患者在什么时刻最难受 → 打开哪一页 → 得到什么产物」。
> 页面树（10 一级 / 29 二级，评审修订后）由这三条流反推，与 SCENARIOS S 编号互相引用。

## 流一：一次确诊就诊（新诊断，术后拿到病理+分子报告）→ S01

- 时刻：术后两周，病理与基因检测结果到手。"IDH 野生型""MGMT 未甲基化"读不懂；放疗科约好了，听说还要"同步吃化疗药"，家属在群里看到"电场"两个字开始焦虑。
- 打开：看板（双主体：患者看"现在可以做"，照护者看"今天他该做什么"）→ 我的瘤 · 分子档案（逐项三态 + 人话解释 + 检测日期）→ 我的瘤 · 手术与切除（医生写的 GTR/STR 是什么意思）。
- 产物：分子档案摘要（可导出）＋自动生成的问题清单条目（"MGMT 结果对化疗选择意味着什么，请医生解释"）。
- 双主体注意：解释页对患者用大字白话；照护者视角提供"逐项勾选已问过"。
- 页面树反推：这条流经过 看板/我的瘤(分子档案/手术/病理原文) → 三个二级成立。

## 流二：一次自查/日常记录（治疗期，家中）→ S02/S03/S05/S06/S09/S11

- 时刻：同步放化疗第 3 周。TMZ 服药日记越记越乱；电场贴片底下开始痒；凌晨患者有一次"愣神两分钟"，照护者说不清那算不算发作；这周血象报告白细胞 2.8，人没劲。
- 打开：放化疗日历（今天 D 几、该不该吃）→ 电场治疗（佩戴时长 + 贴片与头皮）→ 症状与发作（事件卡片：照护者代记 witnessed_by=CAREGIVER）→ 指标与用药（血象卡 CTCAE 分级 + 背面区间）→ 营养与体重（进食记录，激素语境说明）。
- 产物：当天记录 + 一条条"复诊时要问"的积累；激素与症状同轴时间线让"减量→头痛"的时间先后可见。
- 双主体注意：发作由照护者代记；照护者自己的情绪记录走 照护与家事 · 当下感受（visibility=private，默认不导出）。
- 页面树反推：这条流经过 放化疗日历/电场/症状与发作/指标与用药/营养 五条线 → 五条线全部成立，且"电场治疗"独立成线（家族独有）。

## 流三：一次复查（随访 MRI 之后）→ S04/S08/S12

- 时刻：术后 5 个月，复查 MRI 报告写"术区强化范围较前增大，假性进展待排"。全家陷入恐慌；下周三就要复诊，不知道该带什么、问什么；家属开始搜"复发 临床试验"。
- 打开：随访影像 · MRI 并列（本次与历次逐条并排：结论原文/当时激素/当时 KPS——只并列事实）→ 随访影像 · 问题清单（生成"是否需要灌注成像""激素减量后影像怎么读"）→ 复诊与试验 · 就诊准备与导出（fact/view 两区，private 自动过滤）→ 复诊与试验 · 试验线索（GBM 口径四通道，"登记状态，未核实"常驻）。
- 产物：复诊摘要（并排事实 + 问题清单）＋收藏的试验线索。
- 双主体注意：摘要导出自动过滤 private；照护决策话题（"如果确认复发，还要不要二次手术"）留在 照护与家事 · 决策与 ACP，不混进复诊摘要。
- 页面树反推：随访影像独立成线（家族独有）+ 复诊与试验合并线成立。
